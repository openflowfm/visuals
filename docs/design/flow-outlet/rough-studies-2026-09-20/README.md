# Flow outlet rough studies

30 variations generated with the built-in image_gen tool. All outputs retained, including constraint failures. These are visual assessments, not usability validation or an approved visual system.

The disclosure rule (H) reads most clearly. Replacement (E) communicates preservation reasonably well. Stable sockets during range expansion (G), unambiguous drop targets (D), and strictly local disclosure (F) remain unresolved.

Exact submitted prompts and source paths are in manifest.json.
